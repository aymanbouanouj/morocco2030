# Public Asset Policy

The publication build contains only:

- original project placeholder identity files under `brand/`;
- original type-specific fallback illustrations under `placeholders/`;
- the MIT-licensed `flag-icons` runtime package under `images/flag/`.

Official tournament artwork, sponsor logos, unverified photographs, design-reference captures, and local uploads are intentionally excluded from the public repository.

Do not add an asset without recording its creator/source, license, required attribution, and redistribution status in `THIRD_PARTY_ASSETS.md`.
