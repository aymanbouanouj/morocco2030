## Exemples rapides

- If you want to change the displayed match count, do not hardcode it. It comes from FD-WC scoped `MatchFixture` queries in `Site\HomeController`, `Site\SiteController`, and `Admin\DashboardController`; table `matches`; tests `FootballDataPublicConsistencyTest`.
- If you want to refresh match results, run `php artisan football-data:reconcile-matches`.
- If you want to publish news, keep category `Tournament Updates` active, create draft as Journalist, submit for review, publish as Chief Editor/Super Admin.
- If you want a partner logo to appear publicly, upload it from Admin Partners; it is stored in `partners.logo_path` and rendered by `Partner::logoUrl()`.
- If Media Review count is wrong, check `Admin\MediaReadinessController`, `MediaFile`, `MediaRelation`, and contextual paths such as `partners.logo_path`.
